# Dryforge — issues

Bug reports and feature requests for [Dryforge](https://dryforge.app).

**Issues here are public.** Anyone can read them. Do not paste your code, file paths, prompts, chat content, tokens or passwords into an issue.

- **Something does not work** → [open a bug report](../../issues/new?template=bug.yml)
- **Something should exist** → [open a feature request](../../issues/new?template=feature.yml)
- **The report needs your code to reproduce** → email contact@dryforge.dev instead
- **A security problem** → email security@dryforge.dev. Do not open an issue.

When a report is taken on, it is closed with the build that will carry the fix. If that build does not fix it, the issue is opened again.
