# Security

**Do not open a public issue for a security problem.**

Email **security@dryforge.dev**. Include what you found and how to reproduce it. You will get an answer.

Dryforge runs on the person's own computer and every request to a model leaves from it, so what is sent to a model cannot be hidden — that limit is written down rather than guarded. Reports about anything else are welcome: the licence server, the relay, the link between a person's own computers, the stored formats, the signed build, and the way the app and the engine speak.
